# 교착 상태 필요조건

> 교착 상태는 네 가지 조건이 **모두 동시에** 성립할 때만 발생한다 — 하나라도 깨면 예방 가능

## 교착 상태의 4가지 필요조건

| 조건 | 내용 |
|---|---|
| 상호 배제 | 한 자원을 한 번에 하나의 프로세스만 사용할 수 있음 (공유 불가) |
| 비선점 | 다른 프로세스의 자원을 강제로 빼앗을 수 없음 (자발적 반납만 가능) |
| 점유와 대기 | 자원을 쥔 채로 다른 자원을 추가로 기다림 |
| 원형 대기 | 프로세스들이 원(사이클) 형태로 서로의 자원을 기다림 |

- 네 조건은 **필요조건** : 하나라도 성립하지 않으면 교착 상태는 발생하지 않는다
- 따라서 교착 상태 **예방**은 이 네 조건 중 하나를 의도적으로 깨뜨리는 방식으로 이뤄진다

<details><summary>네 조건이 '필요조건'이라는 말의 의미는?</summary>

교착 상태가 발생했다면 네 조건이 반드시 모두 성립해 있었다는 뜻이다. <br>
거꾸로 네 조건이 모두 갖춰졌다고 항상 교착이 나는 것은 아니다(충분조건 아님). <br>
그래서 예방은 네 조건 중 하나만 깨면 되고, 그것으로 교착을 막을 수 있다.
</details>

## 식사하는 철학자 문제

> 교착 상태의 네 조건을 한 번에 보여주는 고전적 예시

**상황 설정**

- 원형 식탁에 철학자 5명이 앉아 있고, 각자 사이에 젓가락(포크)이 1개씩 총 5개
- 식사하려면 **양쪽 젓가락 2개**를 모두 들어야 함
- 모든 철학자가 동시에 **왼쪽 젓가락을 든 뒤 오른쪽 젓가락을 기다리면** → 전원이 멈춤 (교착 상태)

**네 조건과의 대응**

| 필요조건 | 철학자 문제에서 |
|---|---|
| 상호 배제 | 젓가락은 한 명만 쥘 수 있음 |
| 비선점 | 남의 젓가락을 뺏을 수 없음 |
| 점유와 대기 | 왼쪽 젓가락을 쥔 채 오른쪽을 기다림 |
| 원형 대기 | 모두가 오른쪽 사람의 젓가락을 기다려 원형을 이룸 |

**해결 아이디어 (조건 깨기)**

| 방법 | 깨는 조건 |
|---|---|
| 젓가락 2개를 다 잡을 수 있을 때만 잡게 함 | 점유와 대기 |
| 철학자 수보다 자리(또는 동시 식사 인원)를 제한 | 원형 대기 |
| 한 명은 오른쪽부터 잡게 함 (잡는 순서를 다르게) | 원형 대기 |

## 🔑 최종 정리

> 한 줄 요약: 교착 상태는 상호 배제·비선점·점유와 대기·원형 대기 네 조건이 모두 성립할 때만 발생하며(식사하는 철학자 문제가 대표 예), 이 중 하나만 깨뜨리면 교착을 예방할 수 있다
