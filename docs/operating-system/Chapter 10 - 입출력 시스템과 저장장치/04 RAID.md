# RAID

> RAID(Redundant Array of Independent Disks) : 여러 디스크를 묶어 장애에 대비(중복 저장)하거나 속도를 높이는(병렬 처리) 기술

## RAID의 개요

- 디스크는 기계 장치라 **고장 확률**이 높음 → 데이터 유실 대비 필요
- 두 가지 목표

| 목표 | 수단 |
|---|---|
| 안정성 (장애 대비) | 같은 데이터를 여러 디스크에 **중복 저장**, 또는 패리티로 복구 |
| 성능 | 데이터를 여러 디스크에 나눠 **병렬로 읽고 쓰기** (스트라이핑) |

| 핵심 용어 | 내용 |
|---|---|
| 스트라이핑 (striping) | 데이터를 쪼개 여러 디스크에 분산 저장 |
| 미러링 (mirroring) | 같은 데이터를 다른 디스크에 복사 |
| 패리티 (parity) | 데이터 복구용 추가 정보 — 디스크 1개 고장 시 나머지+패리티로 복원 |

---

## RAID 0 (스트라이핑)

- 데이터를 N개 디스크에 나눠 **동시에 입출력** → 이론상 N배 속도
- **장애 대비 전혀 없음** — 디스크 1개만 고장 나도 전체 데이터 유실
- 속도만 필요할 때 사용

---

## RAID 1 (미러링)

- 같은 데이터를 **두 디스크에 복사** 저장
- 하나가 고장 나도 데이터 보존 — 안정성 최고
- 용량 효율 50% (디스크 절반이 복사본), 쓰기 2회 발생

---

## RAID 2

- 비트 단위 스트라이핑 + **해밍 코드(ECC)** 전용 디스크로 오류 검출·복구
- 해밍 코드 디스크가 많이 필요 (데이터 4 + 체크 3 등) → 비용 과다, **현재 안 씀**

---

## RAID 3

- **바이트(섹터) 단위** 스트라이핑 + **패리티 전용 디스크 1개**
- 해밍 코드 대신 패리티로 복구 → RAID 2보다 경제적
- 모든 입출력이 전 디스크에 걸침 → 작은 요청도 전체 디스크 동원

---

## RAID 4

- **블록 단위** 스트라이핑 + 패리티 전용 디스크 1개
- 블록 단위라 작은 읽기는 해당 디스크만 사용 가능
- 문제 : 모든 쓰기가 패리티 디스크를 갱신 → **패리티 디스크 병목**, 패리티 디스크만 빨리 마모

---

## RAID 5

- RAID 4의 병목 해결 — **패리티를 모든 디스크에 분산** 저장
- 쓰기 부하가 고르게 분산, 디스크 1개 고장까지 복구 가능
- 실무에서 가장 널리 쓰이는 단일 패리티 구성

---

## RAID 6

- **패리티를 2개** 저장 (서로 다른 디스크에)
- **디스크 2개 동시 고장**까지 복구 가능 — 안정성 상승
- 쓰기마다 패리티 2개 갱신 → 쓰기 성능은 RAID 5보다 낮음

---

## RAID 10

- **RAID 1 (미러링) + RAID 0 (스트라이핑)** 조합
- 미러링된 쌍들을 스트라이핑 → 속도와 안정성 동시 확보
- 용량 효율 50%, 비용 높음 — 성능·안정성 모두 중요한 DB 서버 등에 사용

---

## RAID 50과 RAID 60

| 구성 | 내용 |
|---|---|
| RAID 50 | RAID 5 묶음들을 RAID 0으로 스트라이핑 — RAID 5의 안정성 + 속도 향상 |
| RAID 60 | RAID 6 묶음들을 RAID 0으로 스트라이핑 — 더 높은 안정성 + 속도 향상 |

---

## 구성 비교

| 레벨 | 방식 | 장애 허용 | 특징 |
|---|---|---|---|
| 0 | 스트라이핑 | 0개 | 속도만, 유실 위험 |
| 1 | 미러링 | 1개 | 안정성, 용량 50% |
| 2 | 비트 + 해밍 코드 | 1개 | 비용 과다, 사용 안 함 |
| 3 | 바이트 + 패리티 1 | 1개 | 전 디스크 동원 |
| 4 | 블록 + 패리티 1 | 1개 | 패리티 병목 |
| 5 | 블록 + 패리티 분산 | 1개 | 실무 표준 |
| 6 | 패리티 2개 분산 | 2개 | 안정성↑, 쓰기↓ |
| 10 | 미러링 + 스트라이핑 | 쌍마다 1개 | 고성능·고안정, 고비용 |

<details><summary>패리티 1개로 어떻게 데이터를 복구하는가?</summary>

패리티는 각 디스크의 같은 위치 비트들을 XOR한 값이다. <br>
디스크 하나가 고장 나면, 남은 디스크들과 패리티를 다시 XOR해서 <br>
사라진 비트를 역산할 수 있다. 단, 2개가 동시에 고장 나면 역산이 불가능하다(→ RAID 6).
</details>

---

## 🔑 최종 정리

> 한 줄 요약: RAID는 여러 디스크를 묶어 속도(스트라이핑)와 안정성(미러링·패리티)을 얻는 기술로, RAID 0은 속도만, 1은 복사, 5는 패리티 분산(실무 표준), 6은 이중 패리티(2개 고장 허용), 10은 미러링+스트라이핑 조합이다
