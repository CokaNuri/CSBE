# 디스크 스케줄링

> 디스크 스케줄링 : 여러 디스크 요청의 처리 순서를 재배열해 헤드 이동 거리(탐색 시간)를 최소화하는 기법

## FCFS 디스크 스케줄링

> 들어온 순서대로 처리 (First Come First Served)

- 구현 가장 단순, 공평함
- 요청 순서가 흩어져 있으면 헤드가 **왔다 갔다** → 이동 거리 낭비

---

## SSTF 디스크 스케줄링

> 현재 헤드 위치에서 가장 가까운 요청부터 처리 (Shortest Seek Time First)

- 이동 거리 관점에서 효율적
- 문제 : 먼 곳의 요청은 계속 밀림 → **아사(starvation) 현상**
- 가까운 요청이 계속 들어오면 먼 요청은 영원히 처리 안 될 수 있음

---

## 블록 SSTF 디스크 스케줄링

> 요청을 일정 블록(묶음)으로 나누고, 블록 안에서만 SSTF 적용

- 블록 단위로는 들어온 순서 보장 → **아사 방지 (공평성 확보)**
- 블록 안에서는 SSTF → 어느 정도 효율 유지
- 효율은 순수 SSTF보다 낮음 (공평성과 효율의 절충)

---

## SCAN 디스크 스케줄링

> 헤드가 한쪽 끝에서 반대쪽 끝까지 이동하며 경로상의 요청을 모두 처리 — 엘리베이터 방식

- 끝에 도달하면 방향을 바꿔 반대로 이동하며 처리
- SSTF의 아사 문제 완화
- 문제 : **중앙 트랙**은 헤드가 자주 지나가고 **양 끝**은 드물게 지나감 → 위치별 불공평

---

## C-SCAN 디스크 스케줄링

> SCAN의 변형 — 한 방향으로만 처리하고, 끝에 도달하면 처리 없이 반대쪽 끝으로 복귀

- 모든 트랙이 같은 빈도로 서비스받음 → SCAN의 위치별 불공평 해소
- 복귀 이동은 요청을 처리하지 않는 **낭비 이동**

---

## LOOK 디스크 스케줄링

> SCAN의 개선 — 디스크 끝까지 가지 않고, 마지막 요청 위치에서 방향 전환

- "더 갈 필요가 있는지 **보고(look)**" 움직임
- 불필요한 끝까지의 이동 제거 → SCAN보다 효율적

---

## C-LOOK 디스크 스케줄링

> C-SCAN의 개선 — 마지막 요청 위치에서 바로 첫 요청 위치로 복귀

- C-SCAN의 공평성 + LOOK의 이동 절약

---

## SLTF 디스크 스케줄링

> 회전 지연 시간이 가장 짧은 요청부터 처리 (Shortest Latency Time First)

- 헤드가 고정된 **드럼형 장치**(트랙마다 헤드가 있는 구조)에 사용
- 탐색 시간이 없으므로 **회전 지연**만 최소화하면 됨
- 섹터 위치 순서대로 큐를 재배열 = **섹터 큐잉(sector queuing)**

---

## 알고리즘 비교

| 알고리즘 | 기준 | 특징 |
|---|---|---|
| FCFS | 도착 순서 | 공평하지만 비효율 |
| SSTF | 가장 가까운 요청 | 효율적이지만 아사 발생 |
| 블록 SSTF | 블록 내 SSTF | 공평성 확보, 효율 절충 |
| SCAN | 한쪽 끝 ↔ 반대쪽 끝 | 엘리베이터 방식, 중앙·끝 불공평 |
| C-SCAN | 한 방향만 처리 | 트랙별 공평, 복귀 낭비 |
| LOOK | 마지막 요청에서 전환 | SCAN 개선 |
| C-LOOK | 마지막 요청에서 복귀 | C-SCAN 개선, 실사용 유리 |
| SLTF | 최소 회전 지연 | 헤드 고정 장치(드럼)용 |

<details><summary>SSD에서는 디스크 스케줄링이 왜 의미가 없어지는가?</summary>

디스크 스케줄링의 목적은 헤드의 물리적 이동(탐색 시간)을 줄이는 것인데, <br>
SSD는 헤드와 회전 자체가 없어 어떤 순서로 읽어도 접근 시간이 거의 같다. <br>
그래서 SSD에서는 전통적 스케줄링 대신 단순한 큐 처리를 쓰는 경우가 많다.
</details>

## 🔑 최종 정리

> 한 줄 요약: 디스크 스케줄링은 헤드 이동을 줄이기 위한 요청 재배열로, FCFS(순서)→SSTF(최근접, 아사)→블록 SSTF(공평 절충)→SCAN/C-SCAN(엘리베이터)→LOOK/C-LOOK(마지막 요청에서 전환)으로 발전했고, 헤드 고정 장치는 회전 지연만 줄이는 SLTF(섹터 큐잉)를 쓴다
