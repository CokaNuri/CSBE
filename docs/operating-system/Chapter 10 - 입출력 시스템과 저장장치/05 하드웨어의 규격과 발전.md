# 하드웨어의 규격과 발전

> 저장장치·주변장치를 연결하는 포트와 매체 규격의 발전사 — 병렬에서 직렬로, 더 빠르게

## 포트의 규격

**하드디스크 연결 포트**

| 계열 | 규격 | 특징 |
|---|---|---|
| 병렬 | IDE → EIDE (PATA) | 넓은 리본 케이블, 병렬 전송 — 속도 한계·간섭 |
| 직렬 | **SATA** | 가는 케이블, 직렬 전송 — 더 빠르고 핫스왑 지원 |
| 서버용 병렬 | SCSI | 여러 장치 연결, 서버에서 사용 |
| 서버용 직렬 | **SAS** (Serial Attached SCSI) | SCSI의 직렬 버전 |

- 흐름 : **병렬 → 직렬** 전환이 공통 — 병렬은 선이 많아질수록 신호 간섭·동기화 문제 발생

**범용 포트**

- **USB** : 저속·고속 주변장치를 하나의 포트 규격으로 통일, 전원 공급 + 핫스왑
- 버전이 오를수록 전송 속도 증가 (USB 1.0 → 2.0 → 3.x …)

<details><summary>병렬보다 직렬이 더 빨라진 이유는?</summary>

병렬은 여러 선의 신호가 동시에 도착해야 해서 속도를 올리면 <br>
선 간 간섭과 도착 시점 차이(스큐) 문제가 커진다. <br>
직렬은 선이 적어 간섭이 없고 클럭을 극단적으로 올릴 수 있어 결과적으로 더 빠르다.
</details>

## CD의 규격

- CD의 기본 속도 **1배속 = 150KB/s** (음악 CD 재생 속도 기준)
- N배속 = 150KB/s × N (예: 48배속 ≈ 7.2MB/s)

| 매체 | 용량 | 특징 |
|---|---|---|
| CD | 약 700MB | 적외선 레이저 |
| DVD | 약 4.7GB~ | 더 짧은 파장 레이저 → 밀도 증가 |
| 블루레이 | 약 25GB~ | 청자색 레이저 → 가장 높은 밀도 |

- 레이저 파장이 짧을수록 더 작은 점을 읽을 수 있어 **저장 밀도 증가**

## 그래픽카드의 발전

| 단계 | 규격 | 특징 |
|---|---|---|
| 초기 | PCI (범용 버스) | 그래픽 데이터 폭증에 대역폭 부족 |
| 그래픽 전용 | AGP | 그래픽카드 전용 포트로 분리 |
| 현대 | **PCIe (PCI Express)** | 직렬 레인(lane) 다발 — x1, x4, x16처럼 레인 수로 대역폭 확장 |

- 그래픽 처리 수요(3D, 고해상도) 증가 → 전용 고속 포트로 진화
- GPU : 그래픽 연산 전용 프로세서 — 단순 연산을 **대규모 병렬**로 처리 (현재는 AI 연산에도 활용)

## 🔑 최종 정리

> 한 줄 요약: 연결 규격은 병렬(IDE/EIDE, SCSI)에서 직렬(SATA, SAS, USB, PCIe)로 진화하며 속도를 높였고, CD는 1배속 150KB/s 기준에 레이저 파장을 줄여 DVD·블루레이로 용량을 키웠으며, 그래픽카드는 PCI→AGP→PCIe로 전용 고속 포트화됐다
