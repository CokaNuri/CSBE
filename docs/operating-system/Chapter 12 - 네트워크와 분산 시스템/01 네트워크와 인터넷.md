# 네트워크와 인터넷

> 네트워크 : 여러 컴퓨터를 통신 회선으로 연결해 데이터를 주고받는 체계 — 인터넷은 네트워크들의 네트워크

## 통신과 네트워크

**네트워크의 규모별 분류**

| 종류 | 범위 | 예 |
|---|---|---|
| LAN (근거리) | 건물·학교 등 좁은 지역 | 사내망, 가정 공유기 |
| MAN (도시권) | 도시 단위 | 케이블 방송망 |
| WAN (광역) | 국가·대륙 단위 — LAN들을 연결 | 인터넷, 통신사 백본 |

**네트워크 구성 요소**

| 요소 | 역할 |
|---|---|
| 허브 | 받은 신호를 연결된 모든 포트로 전달 |
| 스위치 | MAC 주소를 보고 **목적지 포트로만** 전달 |
| 라우터 | IP 주소를 보고 **다른 네트워크로** 경로 결정 |
| 게이트웨이 | 서로 다른 프로토콜의 네트워크 연결 |

---

**프로토콜과 계층 구조**

> 프로토콜 : 통신하는 양쪽이 지켜야 할 약속(형식·절차) — 복잡한 통신을 **계층**으로 나눠 정의

| OSI 7계층 | TCP/IP 4계층 | 역할 | 예 |
|---|---|---|---|
| 응용 / 표현 / 세션 | 응용 | 사용자 서비스 | HTTP, FTP, DNS, SMTP |
| 전송 | 전송 | 프로세스 간 신뢰성 있는 전달 (포트) | TCP, UDP |
| 네트워크 | 인터넷 | 목적지까지 경로 선택 (IP 주소) | IP, ICMP |
| 데이터 링크 / 물리 | 네트워크 접근 | 인접 장치 간 전송, 전기 신호 | 이더넷, Wi-Fi |

- 보낼 때 위 계층부터 헤더를 붙이며 내려가고(**캡슐화**), 받을 때 아래부터 떼며 올라감
- 데이터는 작은 **패킷**으로 나뉘어 전송 → 회선을 여럿이 나눠 쓸 수 있음 (패킷 교환)

| 전송 프로토콜 | 특징 |
|---|---|
| TCP | 연결형 — 순서 보장, 재전송, 흐름·혼잡 제어 → 신뢰성 |
| UDP | 비연결형 — 확인 절차 없음 → 빠름 (스트리밍, 게임, DNS) |

**인터넷 주소**

| 주소 | 내용 |
|---|---|
| MAC 주소 | 네트워크 카드 고유 물리 주소 (48비트) |
| IP 주소 | 네트워크상 논리 주소 — IPv4(32비트), IPv6(128비트) |
| 포트 번호 | 한 컴퓨터 안의 **프로세스** 구분 (HTTP 80, HTTPS 443) |
| 도메인 이름 | 사람이 읽는 주소 — **DNS**가 IP 주소로 변환 |

<details><summary>IP 주소만으로 부족하고 포트 번호가 필요한 이유는?</summary>

IP 주소는 컴퓨터(호스트)까지만 찾아간다. <br>
한 컴퓨터에서 웹 서버, DB, 메신저 등 여러 프로세스가 동시에 통신하므로 <br>
도착한 데이터를 어느 프로세스에 넘길지 구분하는 번호가 포트다.
</details>

## 유무선 통신

**유선 통신**

| 매체 | 특징 |
|---|---|
| 트위스티드 페어 (랜선) | 구리선 두 가닥을 꼬아 간섭 감소 — 가장 흔함 (UTP, Cat.5e/6) |
| 동축 케이블 | 중심 도체 + 차폐 — 케이블 TV |
| 광섬유 | 빛으로 전송 — 고속·장거리, 전자기 간섭 없음 (백본망) |

- 유선 LAN 표준 = **이더넷** — 충돌 감지 방식 **CSMA/CD** (보내다 충돌 감지 시 대기 후 재전송)

**무선 통신**

| 기술 | 범위 | 용도 |
|---|---|---|
| Wi-Fi (무선 LAN) | 수십 m | AP(공유기)를 통한 인터넷 접속 |
| 블루투스 | 약 10m | 이어폰, 키보드 등 개인 기기 연결 |
| NFC | 수 cm | 교통카드, 간편결제 |
| 이동통신 (LTE, 5G) | 기지국 단위 (셀) | 스마트폰 데이터 통신 |

- 무선은 충돌 감지가 어려워 **CSMA/CA** (보내기 전에 충돌을 **회피**) 사용
- 무선은 이동성이 장점이지만 간섭·도청에 취약 → 암호화(WPA2/WPA3) 필요

## 🔑 최종 정리

> 한 줄 요약: 네트워크는 규모에 따라 LAN·MAN·WAN으로 나뉘고, 통신 약속인 프로토콜은 OSI 7계층/TCP/IP 4계층으로 나뉘어 IP 주소로 호스트를, 포트로 프로세스를 찾으며, 전송 매체는 유선(랜선·광섬유, 이더넷 CSMA/CD)과 무선(Wi-Fi·블루투스·이동통신, CSMA/CA)으로 구분된다
