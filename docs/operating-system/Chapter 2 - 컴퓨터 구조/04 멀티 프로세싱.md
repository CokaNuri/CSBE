# 멀티 프로세싱

> 프로세서(코어)를 여러 개 사용하거나, 하나의 코어에서 여러 명령어를 동시에 처리하여 성능을 높이는 기술

## 멀티코어 시스템

### 단일 프로세서 시스템의 한계

> 단일 프로세서 시스템 : 컴퓨터 한 대에 프로세서(CPU)가 하나 달린 시스템 — 프로세서 하나가 한 번에 하나의 작업만 처리

**단일 프로세서에서 성능을 높이는 방법과 그 한계**

| 방법 | 한계 |
|---|---|
| CPU 클록을 높인다 | 클록을 높이면 발열 문제 발생 → 현재 기술로는 5GHz가 넘는 CPU 개발이 어려움 |
| 캐시 크기를 늘린다 | 비용 문제가 발목을 잡음 |

→ 클록·캐시로는 한계에 도달했기 때문에, **코어를 여러 개 만들거나 동시에 실행 가능한 명령의 개수를 늘리는** 방향으로 발전

### 멀티 프로세서 시스템

> 멀티 프로세서 시스템 : 성능을 높이기 위해 프로세서를 여러 개 설치하여 사용하는 시스템

- 프로세서마다 **레지스터와 캐시**를 가짐
- 모든 프로세서가 **시스템 버스를 통해 메인메모리를 공유**
- 장점 : 많은 작업을 동시에 실행할 수 있음

**볶음밥 비유 (그림 2-28)**

- 볶음밥 하나 만드는 데 40분 → 한 주방에서 2개 만들면 80분
- 주방을 2개로 늘리면 → 40분 만에 볶음밥 2개 (주방 = 프로세서)

### 멀티코어 시스템

> 멀티코어 시스템 : 기존 시스템을 유지한 채 멀티 프로세싱을 할 수 있게, 하나의 칩 안에 코어를 여러 개 넣은 시스템

- 단일 프로세서 → 멀티 프로세서로 바꾸려면 보드 설계 변경을 비롯해 많은 변화가 필요 (비용 큼)
- 대신 CPU의 핵심이 되는 **코어**를 여러 개 만들어 하나의 칩에 넣음
- **듀얼코어** : 코어 2개, **쿼드코어** : 코어 4개
- 요즘 컴퓨터·스마트폰용 CPU의 "듀얼코어/쿼드코어"는 CPU가 여러 개가 아니라 **주요 기능을 담당하는 코어가 여러 개**라는 뜻

| 구분 | 멀티 프로세서 시스템 | 멀티코어 시스템 |
|---|---|---|
| 구조 | CPU 칩 자체를 여러 개 설치 | 하나의 칩 안에 코어를 여러 개 |
| 비용 | 보드 설계 변경 등 비용 큼 | 기존 시스템 유지 가능 |

## CPU 멀티스레드

### 명령어 병렬 처리

> 명령어 병렬 처리 : 하나의 코어에서 여러 개의 명령어를 동시에 처리하는 것

- 레스토랑 비유 : 요리사가 2명이면 한 사람이 재료를 손질하는 동안 다른 요리사가 재료를 볶아 두 가지 요리를 동시에 진행

**볶음밥 조리의 병렬 처리 (그림 2-29, 2-30)**

- 볶음밥 하나 = 세척(10분) → 손질(10분) → 조리(10분) → 마무리(10분) = 40분
- 작업 장소가 겹치지 않게 진행 : A가 세척을 마치고 손질에 들어가면 B가 세척 시작 …

| 시간 | 10분 | 20분 | 30분 | 40분 | 50분 | 60분 |
|---|---|---|---|---|---|---|
| A | 세척 | 손질 | 조리 | 마무리 | | |
| B | | 세척 | 손질 | 조리 | 마무리 | |
| C | | | 세척 | 손질 | 조리 | 마무리 |

- 순서대로 하면 120분 걸릴 볶음밥 3개를 **60분 만에** 완성 — 시간이 거의 반으로 줄어듦

### 스레드와 CPU 멀티스레드

| 용어 | 내용 |
|---|---|
| 스레드 | CPU가 처리할 수 있는 **작업의 단위** |
| CPU 멀티스레드 | 여러 개의 스레드를 동시에 처리하는 방법 |

### 하이퍼스레드

> 인텔의 하이퍼스레드 : 하나의 코어에서 2개의 명령어를 거의 동시에 실행하는 기술

- 명령어 병렬 처리를 사용하면 코어는 하나지만 2개의 명령어가 거의 동시에 처리되어 **마치 코어가 2개 있는 것처럼** 보임

**예 : 인텔 i7-3770 (그림 2-31)**

- 4코어 + 하이퍼스레드 지원 (코어당 스레드 2개)
- 논리 프로세서 개수 = 4 × 2 = **8개** → CPU가 8개 달린 컴퓨터처럼 보임
- 작업 관리자에서 확인 : 소켓 1개(CPU 1개), 코어 4개, 논리 프로세서 8개

<details><summary>물리 코어 4개인데 왜 8개처럼 보이는가?</summary>

각 코어가 명령어 병렬 처리(하이퍼스레드)로 2개의 명령어를 거의 동시에 실행할 수 있기 때문이다. <br>
운영체제 입장에서는 명령어를 받아 주는 창구가 8개이므로 논리적인 코어(논리 프로세서)를 8개로 인식한다. <br>
현대의 CPU는 이렇게 하나의 칩에 멀티코어와 명령어 병렬 처리 기능을 한꺼번에 구현한다.
</details>

## 🔑 최종 정리

> 한 줄 요약: 클록·캐시의 한계에 부딪힌 CPU는 하나의 칩에 코어를 여러 개 넣는 멀티코어와, 한 코어에서 여러 명령어를 동시에 처리하는 CPU 멀티스레드(하이퍼스레드)로 발전했으며, 그 결과 4코어 CPU가 논리 프로세서 8개로 보이는 것처럼 물리적 개수 이상의 동시 처리가 가능해졌다
