# 멀티 프로세싱

> 프로세서를 여러 개 사용하거나, 하나의 코어에서 여러 명령어를 동시에 처리하여 성능을 높이는 기술

## 멀티코어 시스템

### 단일 프로세서 시스템의 한계

> 단일 프로세서 시스템 : 컴퓨터 한 대에 프로세서가 하나 달린 시스템 <br> 프로세서 하나가 한 번에 하나의 작업만 처리

**단일 프로세서에서 성능을 높이는 방법과 한계**

| 방법 | 한계 |
|---|---|
| CPU 클록을 높인다 | 클록을 높이면 발열 문제 발생 → 현재 기술로는 5GHz가 넘는 CPU 개발이 어려움 |
| 캐시 크기를 늘린다 | 비용 문제 |

→ **코어를 여러 개 만들거나 동시에 실행 가능한 명령의 개수를 늘리는** 방향으로 발전

### 멀티 프로세서 시스템

> 멀티 프로세서 시스템 : 성능을 높이기 위해 프로세서를 여러 개 설치하여 사용하는 시스템

- 프로세서마다 **레지스터와 캐시**를 가짐
- 모든 프로세서가 **시스템 버스를 통해 메인메모리를 공유**
- 장점 : 많은 작업을 동시에 실행할 수 있음


### 멀티코어 시스템

> 기존 시스템을 유지한 채 멀티 프로세싱을 할 수 있게, 하나의 칩 안에 코어를 여러 개 넣은 시스템

- 단일 프로세서 → 멀티 프로세서로 바꾸려면 보드 설계 변경을 비롯해 많은 변화가 필요
- 대신 CPU의 핵심이 되는 **코어**를 여러 개 만들어 하나의 칩에 넣음
- **듀얼코어** : 코어 2개, **쿼드코어** : 코어 4개

## CPU 멀티스레드

### 명령어 병렬 처리

> 명령어 병렬 처리 : 하나의 코어에서 여러 개의 명령어를 동시에 처리하는 것


### 스레드와 CPU 멀티스레드

| 용어 | 내용 |
|---|---|
| 스레드 | CPU가 처리할 수 있는 **작업의 단위** |
| CPU 멀티스레드 | 여러 개의 스레드를 동시에 처리하는 방법 |

### 하이퍼스레드

> 인텔의 하이퍼스레드 : 하나의 코어에서 2개의 명령어를 거의 동시에 실행하는 기술

- 명령어 병렬 처리를 사용하면 코어는 하나지만 2개의 명령어가 거의 동시에 처리되어 <br> **마치 코어가 2개 있는 것처럼** 보임

## 🔑 최종 정리

> 한 줄 요약: CPU는 하나의 칩에 코어를 여러 개 넣는 멀티코어와, 한 코어에서 여러 명령어를 동시에 처리하는 CPU 멀티스레드로 발전했다
