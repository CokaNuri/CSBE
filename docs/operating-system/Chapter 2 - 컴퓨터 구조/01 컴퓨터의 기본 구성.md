# 컴퓨터의 기본 구성

> 운영체제는 하드웨어를 관리하는 소프트웨어이므로, 운영체제를 이해하려면 컴퓨터 하드웨어의 기본 구성을 먼저 알아야 한다

## 하드웨어의 구성

| 장치 | 구성 요소 | 역할 |
|---|---|---|
| 중앙처리장치 (CPU) | 산술논리 연산장치, 제어장치, 레지스터 | 명령어를 해석하고 실행 |
| 메인메모리 (제1저장장치) | RAM | 실행 중인 프로그램과 데이터 보관 (휘발성) |
| 입력장치 | 키보드, 마우스, 스캐너 등 | 외부 데이터를 컴퓨터로 입력 |
| 출력장치 | 모니터, 프린터, 스피커 등 | 처리 결과를 외부로 출력 |
| 저장장치 (제2저장장치) | HDD, SSD, USB 메모리 등 | 데이터를 영구적으로 보관 (비휘발성) |

**필수장치와 주변장치**

- 필수장치 : CPU, 메인메모리 — 없으면 컴퓨터가 동작하지 않음
- 주변장치 : 입력장치, 출력장치, 저장장치

> 메인메모리는 전력이 끊기면 데이터를 잃어버리기 때문에(휘발성), 데이터를 영구히 보관하려면 저장장치가 필요하다

- 각 장치는 **메인보드** 위에서 **버스**로 연결되어 데이터를 주고받는다

---

## 폰노이만 구조

> CPU, 메모리, 입력장치, 출력장치, 저장장치가 버스로 연결되어 있는 구조

> 핵심 명제 : **"모든 프로그램은 메모리에 올라와야 실행할 수 있다"**

- 이전의 하드와이어드 방식은 다른 작업을 하려면 회로를 바꿔야 했음
- 폰노이만 구조는 **프로그램 내장 방식** — 프로그램을 메모리에 올려 실행하므로 소프트웨어만 바꾸면 다양한 작업 수행 가능
- 오늘날 컴퓨터 대부분이 폰노이만 구조를 따름

<details><summary>왜 "메모리에 올라와야 실행할 수 있다"가 중요한가?</summary>

CPU는 저장장치(하드디스크 등)에 직접 접근하지 않고 메모리하고만 데이터를 주고받는다. <br>
따라서 실행할 프로그램은 반드시 저장장치에서 메모리로 옮겨져야 하고, 이 때문에 메모리가 컴퓨터의 핵심 작업 공간이 된다. <br>
운영체제의 메모리 관리가 중요한 이유도 여기서 출발한다.
</details>

## 요리사 모형

> 컴퓨터의 작동 구조를 요리사가 요리하는 과정에 비유한 모형

| 요리사 모형 | 컴퓨터 |
|---|---|
| 요리사 | CPU |
| 도마 (작업 공간) | 메모리 |
| 보관 창고 | 저장장치 |
| 재료를 가져오는 과정 | 데이터 이동 (버스) |

- 요리사는 창고(저장장치)에 직접 가서 요리하지 않고, 재료를 도마(메모리) 위로 가져와 요리한다
- 도마가 크면 요리(작업)가 빨라지듯, 메모리가 크면 작업이 수월해진다

**메모리와 저장장치의 트레이드오프**

| 구분 | 메모리 | 저장장치 |
|---|---|---|
| 속도 | 빠름 | 느림 |
| 가격 | 비쌈 | 쌈 |
| 용량 | 작음 | 큼 |
| 휘발성 | 휘발성 | 비휘발성 |

## 기초 용어 정리

| 용어 | 내용 |
|---|---|
| 클록 | CPU에 일정한 박자를 공급하는 장치. 이 박자에 맞춰 명령어가 실행됨 |
| 헤르츠 (Hz) | 클록틱이 1초에 몇 번 발생하는지 나타내는 단위. 3.4GHz = 1초에 약 34억 번 |
| 시스템 버스 (FSB) | 메모리와 주변장치를 연결하는 버스 (전면 버스) |
| CPU 내부 버스 (BSB) | CPU 내부의 장치(ALU, 레지스터 등)를 연결하는 버스 (후면 버스) |

- CPU 내부 버스의 속도는 CPU 클록과 같고, 시스템 버스보다 훨씬 빠르다
- CPU와 메모리의 속도 차이가 발생하는 근본 원인 → 캐시 등 성능 향상 기술이 필요해짐
