# 컴퓨터의 기본 구성


## 하드웨어의 구성

| 장치 | 구성 요소 | 역할 |
|---|---|---|
|  CPU | 산술논리 연산장치, 제어장치, 레지스터 | 명령어를 해석하고 실행 |
| 메인메모리  | RAM | 실행 중인 프로그램과 데이터 보관  |
| 입력장치 | 키보드, 마우스, 스캐너 등 | 외부 데이터를 컴퓨터로 입력 |
| 출력장치 | 모니터, 프린터, 스피커 등 | 처리 결과를 외부로 출력 |
| 저장장치  | HDD, SSD, USB 메모리 등 | 데이터를 영구적으로 보관 |

- 각 장치는 **메인보드** 위에서 **버스**로 연결되어 데이터를 주고받는다

---

## 폰노이만 구조

> CPU, 메모리, 입력장치, 출력장치, 저장장치가 버스로 연결되어 있는 구조

>  **모든 프로그램은 메모리에 올라와야 실행할 수 있다**

- 이전의 하드와이어링 방식은 다른 작업을 하려면 회로를 바꿔야 했음
- 폰노이만 구조는 프로그램을 메모리에 올려 실행하므로 소프트웨어만 바꾸면 다양한 작업 수행 가능

---

## 요리사 모형

> 컴퓨터의 작동 구조를 요리사가 요리하는 과정에 비유한 모형

| 요리사 모형 | 컴퓨터 |
|---|---|
| 요리사 | CPU |
| 도마 | 메모리 |
| 보관 창고 | 저장장치 |

- 요리사는 창고에 직접 가서 요리하지 않고, 재료를 도마 위로 가져와 요리한다
- 도마가 크면 요리가 빨라지듯, 메모리가 크면 작업이 수월해진다

## 기초 용어 정리

| 용어 | 내용 |
|---|---|
| 클록 | CPU에 일정한 박자를 만들어내는 것 |
| 헤르츠 (Hz) | 펄스가 1초에 몇 번 발생하는지 나타내는 단위|
| 시스템 버스 (FSB) | 메모리와 주변장치를 연결하는 버스 |
| CPU 내부 버스 (BSB) | CPU 내부의 장치를 연결하는 버스  |

- CPU 내부 버스의 속도는 CPU 클록과 같고, 시스템 버스보다 훨씬 빠르다

**하드웨어 사양 예 (표 2-3)**

| 부품 | 사양 |
|---|---|
| CPU | 인텔 코어 i7 (6코어, 12스레드, 기본 3.7GHz, 최대 5.0GHz, 캐시 20MB) |
| 메인보드 | FSB 3,200MHz |
| 메모리 | DDR4 SDRAM 4GB (3,200MHz) |

- 메인보드의 버스 클록이 최대 3,200MHz → 여기에 연결된 메모리도 3,200MHz로 작동
- CPU 내부 버스(BSB)의 속도는 CPU 클록과 같으므로 시스템 버스(FSB)보다 훨씬 빠름 — 최고 속도 5GHz

## 프로그래밍과 언어

> 컴퓨터에 알려줄 작업을 하나로 모으면 **프로그램**, 프로그램을 만들 때 사용하는 언어가 **프로그래밍 언어**

| 구분 | 내용 |
|---|---|
| 기계어 | 0과 1의 이진수로 된, 컴퓨터가 이해할 수 있는 유일한 언어 |
| 어셈블리어 | 이진수를 문자 형태로 바꾼 것 — 전문가만 사용 |
| 저급언어 | 기계어에 가까운 언어 (기계어, 어셈블리어) |
| 고급언어 | if, for처럼 일반인이 이해할 수 있는 단어로 만든 언어 — 기계어·어셈블리어를 제외한 대부분 (C, C++, 자바, 파이썬 등) |

**컴파일 방식과 인터프리터 방식**

> 컴퓨터는 기계어만 인식하므로 고급언어로 만든 소스코드를 기계어로 번역해야 한다

| 구분 | 컴파일 방식 | 인터프리터 방식 |
|---|---|---|
| 동작 | 소스코드 전체를 번역하여 기계어 실행 파일 생성 | 한 번에 한 문장씩 번역하며 실행 (실행 파일 없음) |
| 최적화 | 반복 작업 삭제, 불필요한 변수 제거 등 최적화 가능 | 위에서부터 한 줄씩 실행되어 전체 최적화 어려움 |
| 대표 언어 | C, C++ | 자바스크립트 |

- 번역 과정 = **컴파일**, 담당 프로그램 = **컴파일러**

## 필수 자료구조

### 큐와 스택

| 구분 | 큐 (queue) | 스택 (stack) |
|---|---|---|
| 구조 | 한쪽으로 넣고 반대쪽으로 나오는 구멍 뚫린 통 | 밑이 막혀 한쪽으로만 넣고 빼는 통 (봉투) |
| 순서 | First In, First Out — 들어간 순서대로 나옴 | First In, Last Out — 나중에 들어온 것이 먼저 나옴 |
| 예 | 대기 줄 (먼저 온 손님 먼저 처리) | 봉투에 담은 햄버거 (마지막에 넣은 것부터 꺼냄) |

- 큐에 자료를 넣는 작업 : **큐잉**

### 배열과 연결 리스트

| 구분 | 배열 (array) | 연결 리스트 (linked list) |
|---|---|---|
| 구조 | 같은 형태의 자료를 **연속된 메모리**에 나열 | 데이터를 **포인터**로 연결 |
| 크기 | 미리 선언해야 함 — 크게 잡으면 낭비, 작게 잡으면 입력 제한 | 필요할 때 메모리를 할당받아 연결 |
| 삽입·삭제 | 중간 삽입 시 뒤 데이터를 모두 옮겨야 함 (관리 어려움) | 포인터만 바꾸면 되므로 간단 |
| 주 용도 | 크기가 어느 정도 정해진 메모리·파일 관리 | 삽입·삭제가 빈번한 테이블 |

- 큐는 배열로도, 연결 리스트로도 구현할 수 있다
