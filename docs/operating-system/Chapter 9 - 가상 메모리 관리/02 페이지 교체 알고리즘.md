# 페이지 교체 알고리즘

> 페이지 교체 알고리즘 : 메모리가 꽉 찼을 때 어떤 페이지를 내보낼지(희생 페이지) 고르는 기준

## 페이지 교체 알고리즘의 개요

- 좋은 알고리즘 = **앞으로 쓰지 않을 페이지**를 내보내 페이지 부재를 최소화하는 것
- 성능 평가 : **페이지 참조열**(접근한 페이지 번호의 나열)을 넣고 페이지 부재 횟수 비교

| 분류 | 알고리즘 |
|---|---|
| 간단한 방식 | 무작위, FIFO |
| 이론상 최적 | 최적(OPT) |
| 최적 근사 (실사용 계열) | LRU, LFU, NUR, FIFO 변형 |

---

## 무작위 페이지 교체 알고리즘

- 아무 페이지나 골라서 내보냄
- 지역성을 전혀 고려하지 않음 → 성능 낮음, 실제로 안 씀 (비교 기준용)

---

## FIFO 페이지 교체 알고리즘

> 가장 먼저 들어온(가장 오래된) 페이지를 내보냄 — 큐로 구현

- 구현 간단
- 문제 : 오래됐지만 **계속 쓰이는 페이지**(예: 전역 변수)도 내보냄 → 성능 저하
- **벨레이디의 역설(Belady's anomaly)** : 프레임을 늘렸는데 페이지 부재가 오히려 늘 수 있음

---

## 최적 페이지 교체 알고리즘

> 앞으로 가장 오랫동안 사용하지 않을 페이지를 내보냄 — 이론상 최고 성능

- 미래의 접근 패턴을 알아야 함 → **실제 구현 불가능**
- 다른 알고리즘의 성능을 평가하는 **기준점** 역할
- LRU·LFU·NUR는 **과거 데이터로 미래를 추정**해 최적에 근접하려는 시도

---

## LRU 페이지 교체 알고리즘

> LRU(Least Recently Used) : 가장 오랫동안 사용하지 않은 페이지를 내보냄 — 시간의 지역성 활용

**구현 방법**

| 방법 | 내용 | 단점 |
|---|---|---|
| 시간 기록 | 접근할 때마다 시각 기록, 가장 오래된 것 교체 | 시간 저장 공간 필요 |
| 카운터 | 접근 순서를 숫자로 기록 | 카운터 공간 필요, 오버플로 |
| 참조 비트 시프트 | 주기적으로 참조 비트를 오른쪽으로 밀어 넣음, 값이 가장 작은 페이지 교체 | 근사치 |

- 최적 알고리즘에 가까운 성능, 실제 시스템에서 널리 쓰이는 계열

---

## LFU 페이지 교체 알고리즘

> LFU(Least Frequently Used) : 사용 횟수가 가장 적은 페이지를 내보냄

- 페이지마다 접근 횟수 카운트
- 단점 : 최근에 들어온 페이지는 횟수가 적어 **방금 가져온 페이지가 쫓겨날 수 있음**, 카운트 공간 필요

---

## NUR 페이지 교체 알고리즘

> NUR(Not Used Recently) : 참조 비트와 변경 비트 2개만으로 LRU에 근접한 성능 — 공간 효율 우수

- 페이지마다 (참조 비트, 변경 비트) 2비트 사용
- 교체 우선순위 : **(0,0) → (0,1) → (1,0) → (1,1)** 순으로 희생 페이지 선택
- 모든 페이지가 (1,1)이 되면 비트를 전부 0으로 리셋
- 추가 공간이 2비트뿐인데 성능은 LRU·LFU와 비슷 → 가성비 좋음

<details><summary>NUR이 변경 비트를 참조 비트보다 뒤에 두는 이유는?</summary>

변경된 페이지는 내보낼 때 스왑 영역에 다시 써야 해서 비용이 크기 때문이다. <br>
같은 '최근 미사용'이라도 쓰기 비용이 없는 (0,0)을 먼저 내보내는 것이 유리하다.
</details>

---

## FIFO 변형 알고리즘

> FIFO의 단순함은 유지하면서 '자주 쓰는 페이지 방출' 문제를 보완

| 알고리즘 | 내용 |
|---|---|
| 2차 기회 알고리즘 | 참조된 적 있는 페이지는 내보내지 않고 **큐의 맨 뒤로 보내** 한 번 더 기회를 줌 |
| 시계 알고리즘 | 원형 큐 + 포인터. 포인터가 돌며 참조 비트 1이면 0으로 바꾸고 지나감, **0인 페이지를 교체** |

- 2차 기회는 큐 중간에서 페이지를 빼 뒤로 옮기는 관리 비용이 있고, 시계 알고리즘은 포인터 하나로 해결

---

## 알고리즘 비교

| 알고리즘 | 기준 | 비고 |
|---|---|---|
| 무작위 | 없음 | 비교 기준용 |
| FIFO | 들어온 순서 | 벨레이디의 역설 |
| 최적 | 미래의 사용 계획 | 구현 불가, 이론상 최고 |
| LRU | 마지막 사용 시점 | 최적 근사, 널리 사용 |
| LFU | 사용 횟수 | 신규 페이지에 불리 |
| NUR | 참조+변경 비트 | 2비트로 LRU급 성능 |
| 2차 기회/시계 | FIFO + 참조 비트 | FIFO 개선 |

---

## 🔑 최종 정리

> 한 줄 요약: 페이지 교체 알고리즘은 희생 페이지를 고르는 기준으로, 이론상 최고인 최적 알고리즘은 구현 불가라 과거 기록으로 미래를 추정하는 LRU(마지막 사용 시점)·LFU(사용 횟수)·NUR(참조·변경 비트 2개)로 근사하며, FIFO는 벨레이디의 역설이 있어 2차 기회·시계 알고리즘으로 보완한다
