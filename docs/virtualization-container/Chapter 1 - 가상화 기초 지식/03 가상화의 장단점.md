# 가상화의 장단점

## 가상화의 장점

- 가상 서버는 소프트웨어이므로 백업이 쉽다 - 하나의 파일로 캡슐화
- 복사와 삭제가 쉽다
- 물리적 네트워크 기기 구성에 의존하지 않고 네트워크 구성을 유연하게 변경 가능
- 네트워크 기기의 관리 및 유지보수가 쉬움

---

## 가상화의 단점

- 서버, 네트워크 관리 외에도 전문 지식이 필요하다
- 도입하고 유지하는 데 비용이 든다
- 물리 서버에 장애가 발생하면 모든 가상 서버에 영향 끼침

---

## 🔑 최종 정리

> 한 줄 요약: 가상화는 쉬운 복구와 유연한 확장이라는 장점이 있지만 물리 서버 장애 시 영향 범위 확대, 운용 복잡성이라는 단점이 있어 시스템 특성에 맞게 선택해야 한다
