# 가상화의 종류

> 가상화는 대상에 따라 **서버 가상화**, **네트워크 가상화**, 그 외(스토리지·데스크톱 등)로 나뉜다

## 서버 가상화란

> 한 대의 물리 서버 위에 여러 대의 **가상 서버**를 만들어 운용하는 기술

- 가상화 소프트웨어가 물리 서버의 CPU·메모리·디스크를 나누어 각 가상 서버에 할당
- 가상 서버마다 독립된 OS와 애플리케이션 실행 — 서로 영향을 주지 않음

| 방식 | 특징 |
|---|---|
| 호스트 OS형 | 호스트 OS 위에 가상화 소프트웨어를 설치해 게스트 OS 실행 |
| 하이퍼바이저형 | 하드웨어 위에 하이퍼바이저를 직접 설치 — 호스트 OS 없음 |
| 컨테이너형 | 호스트 OS의 커널을 공유하고 애플리케이션 실행 환경만 격리 |

---

## 네트워크 가상화란

> 물리적 네트워크 구성과 다른 **논리적 네트워크**를 소프트웨어로 구성하는 기술

- 배선·장비를 바꾸지 않고 네트워크를 나누거나 합치고, 설정을 중앙에서 제어

| 기술 | 내용 |
|---|---|
| VLAN | 하나의 물리 LAN을 여러 논리 LAN으로 분할 |
| 오버레이 네트워크 | 물리 네트워크 위에 터널로 가상 네트워크를 덧씌움 |
| VPN | 공용 회선 위에 가상의 전용선 구축 |
| SDN | 네트워크 제어를 소프트웨어로 중앙 집중 |
| NFV | 라우터·방화벽 같은 네트워크 기기 기능을 소프트웨어로 구현 |
| SD-WAN | 거점 간 WAN을 소프트웨어로 중앙 관리 |

## 그 외의 가상화

| 종류 | 내용 | 예 |
|---|---|---|
| 스토리지 가상화 | 여러 저장장치를 하나의 저장 공간(풀)으로 묶거나 나눠 제공 | RAID, LVM, SAN/NAS |
| 데스크톱 가상화 (VDI) | 데스크톱 환경을 서버에서 실행하고 화면만 단말로 전송 | 원격 근무용 가상 데스크톱 |
| 애플리케이션 가상화 | 애플리케이션을 서버에서 실행하거나 OS와 분리해 배포 | 원격 앱 스트리밍 |
| 메모리 가상화 | 물리 메모리보다 큰 논리 메모리 제공 | 가상 메모리 |

<details><summary>데스크톱 가상화(VDI)를 쓰면 보안상 무엇이 좋을까?</summary>

데이터와 실행 환경이 모두 서버(데이터 센터)에 있고 단말에는 화면만 전송된다. <br>
단말을 분실하거나 도난당해도 데이터가 단말에 남아 있지 않아 정보 유출 위험이 줄고, <br>
OS 패치·보안 설정도 서버에서 일괄 관리할 수 있다.
</details>

## 🔑 최종 정리

> 한 줄 요약: 서버 가상화는 물리 서버 한 대에 여러 가상 서버를 올리는 기술(호스트 OS형·하이퍼바이저형·컨테이너형)이고, 네트워크 가상화는 물리 배선과 다른 논리 네트워크를 구성하는 기술(VLAN·오버레이·VPN·SDN·NFV·SD-WAN)이며, 그 외에 스토리지·데스크톱·애플리케이션 가상화가 있다
