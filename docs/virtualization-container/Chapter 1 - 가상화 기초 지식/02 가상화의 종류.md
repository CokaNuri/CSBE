# 가상화의 종류

> 가상화는 크게 서버 가상화, 네트워크 가상화로 나뉜다

## 서버 가상화란

> 물리 서버를 가상화 하는 것

- 가상화 소프트웨어가 물리 서버의 CPU·메모리·디스크를 나누어 각 가상 서버에 할당
- 가상 서버마다 독립된 OS와 애플리케이션 실행 

---

## 네트워크 가상화란

> 물리적 네트워크 구성과 다른 논리적 네트워크를 소프트웨어로 구성하는 기술

- 물리적 배선·장비를 바꾸지 않고 네트워크를 분할하거나 합치고, 소프트웨어로 설정을 제어

---

## 그 외의 가상화

| 종류 | 내용 |
|---|---|
| 스토리지 가상화 | HDD 같은 스토리지 장치를 가상화하는 기술 |
| 데스크톱 가상화 | 데스크톱 환경을 서버에서 실행하고 네트워크를 통해 접근하는 기술 | 

---

## 🔑 최종 정리

> 한 줄 요약: 서버 가상화는 물리 서버를 가상화하는 기술이고, 네트워크 가상화는 물리 배선과 다른 논리 네트워크를 구성하는 기술이며, 그 외에 스토리지·데스크톱 가상화가 있다
