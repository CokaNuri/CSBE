# 컨테이너 오케스트레이션

> 다수의 컨테이너를 자동으로 관리하고 운영하는 것 


---

## 로드 밸런싱

> 들어오는 요청을 여러 컨테이너에 할당해 부하를 분산하는 것

- 같은 역할의 컨테이너를 여러 개 띄우고 요청을 나누어 전달
- 한 컨테이너에 부하가 몰리는 것을 방지 → 응답 속도 유지
- 일부 컨테이너가 멈춰도 나머지가 처리 → 서비스 지속

---

## 헬스 체크

> 헬스 체크 : 컨테이너가 정상 동작 중인지 확인하는 것

- 컨테이너에 요청을 보내고 정상적으로 응답을 반환하는지 확인
- 이상이 발견된 컨테이너는 로드 밸런서가 요청 대상에서 제외

---

## 스케일링

> 스케일링 : 부하에 맞춰 컨테이너의 수나 성능을 조절하는 것

- 요청이 많은 시간에는 늘리고, 한가한 시간에는 줄여 리소스 소비 최적화
- 리소스 부족 때문에 시스템 다운되는 상황 방지

---

## 오케스트레이션의 중요성

- 관리 및 운영하는 컨테이너 수가 늘어날수록 대응하기가 어려워짐
- 장애 대응·확장·배포를 자동화해 가용성과 운영 효율을 모두 확보

---

## 🔑 최종 정리

> 한 줄 요약: 컨테이너 오케스트레이션은 다수 컨테이너의 관리와 운영을 자동화하는 작업으로, 로드 밸런싱, 헬스 체크, 스케일링이 핵심 기능이다
