# 쿠버네티스의 주요 명령어

> 매니페스트에 원하는 상태를 적고 `kubectl`로 클러스터에 전달 
## 선언형 기술로 클러스터 조작

> 매니페스트 : 객체의 원하는 상태를 적은 **YAML 파일**

---

## 매니페스트에서 객체를 선택하는 방법

- **레이블** : 객체에 붙이는 키-값 쌍 (`app: web`)
- **셀렉터** : 레이블 조건으로 대상 객체를 고름

---

## 파드의 생성/확인/명령어 실행/변경/삭제


```bash
kubectl apply -f pod.yaml          # 생성 (변경 시에도 동일)
kubectl get pods -o wide           # 목록 확인 (IP·노드 포함)
kubectl exec -it web -- /bin/bash  # 컨테이너 안에서 명령어 실행
kubectl delete pod web             # 삭제
```
