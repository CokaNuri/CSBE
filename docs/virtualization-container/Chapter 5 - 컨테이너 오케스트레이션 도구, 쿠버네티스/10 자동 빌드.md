# 자동 빌드

> 프로그램을 변경하는 절차를 자동화 하는 것

## 자동 빌드란

> 자동 빌드 : 소스 코드가 변경되면 컴파일·테스트·**컨테이너 이미지 생성**을 자동으로 수행하는 것

- 코드를 저장소에 푸시하는 것이 트리거
|
---

## 자동 배포란

> 자동 배포 : 프로그램을 자동으로 릴리스하는 것

- 업로드, 데이터베이스 구조 변경, 같은 작업 필요

---

## 이미지 생성부터 배포까지의 절차

```
① 이미지 생성 → ② 레지스트리 등록 → ③ 배포 업데이트  
```

| 단계 | 내용 |
|---|---|
| 이미지 생성 | 도커파일로 이미지 생성 | 
| 레지스트리 등록 | 새로 만든 이미지를 레지스트리에 푸시 |
| 배포 업데이트 | 클러스터에 변경된 이미지 반영 | 


---

## 새로운 파드로 변경하는 방법

| 방식 | 내용 | 특징 |
|---|---|---|
| 재생성 | 기존 파드를 **모두 정지**한 뒤 새 파드 기동 | 단순하지만 중단 발생 |
| 롤링 업데이트 | 기존 파드를 **조금씩** 새 파드로 교체 | 기존 파드와 새로운 파드가 뒤섞임 |


---

## 자동 빌드/배포를 지원하는 도구

- 젠킨스 X, Skaffold, 스피내커 등의 도구 사용 가능

---

## 🔑 최종 정리

> 한 줄 요약: 자동 빌드는 코드 변경 시 테스트와 이미지 생성을, 자동 배포는 레지스트리 등록 후 매니페스트 변경과 클러스터 적용을 자동화하며, 새 파드로의 교체는 롤링 업데이트·재생성 방식이 있고 Jenkins·Skaffold·등이 이를 지원한다
