# 멀티 클라우드

## 멀티 클라우드란

> 여러 클라우드 서비스를 조합해 사용하는 형태

---

## 멀티 클라우드의 필요성

- 가용성 향상 - 한 클라우드에 장애가 나도 다른 클라우드에서 서비스 지속 

---

## 쿠버네티스를 사용한 멀티 클라우드

- 서로 다른 클라우드를 같은 절차로 조작해 운영 복잡성을 줄일 수 있음
- 컨테이너 이미지 + 매니페스트만 있으면 다른 클라우드의 클러스터에도 그대로 배포

```
        같은 매니페스트 / 같은 컨테이너 이미지
     ┌──────────┬──────────┬──────────┐
     ▼          ▼          ▼          ▼
 EKS (AWS)  GKE (GCP)  AKS (애저)  온프레미스 클러스터
```


---

## 멀티 클라우드 구축을 지원하는 도구

| 도구 | 특징 |
|---|---|
| Rancher | 여러 클라우드의 클러스터를 하나의 화면에서 관리 |
| Terraform |  여러 클라우드의 인프라를 **코드**로 정의·구축 |


---

## 🔑 최종 정리

> 한 줄 요약: 멀티 클라우드는 가용성 향상을 위해 여러 클라우드를 함께 쓰는 형태로 어디서나 같은 방식으로 동작하는 쿠버네티스가 이식성의 토대가 되고 Rancher 등이 여러 클러스터의 통합 관리를 지원한다
