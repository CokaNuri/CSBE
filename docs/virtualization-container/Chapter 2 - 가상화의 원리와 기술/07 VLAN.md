# VLAN

> VLAN (Virtual LAN) : 물리적 연결과 관계없이 스위치에서 LAN을 **논리적으로 분할**하는 기술

## VLAN이란

- LAN = 하나의 **브로드캐스트 도메인** (브로드캐스트 프레임이 도달하는 범위)
- VLAN을 나누면 같은 스위치에 연결되어 있어도 **다른 VLAN끼리는 통신 불가** (L2에서 분리)
- 다른 VLAN과 통신하려면 라우터·L3 스위치를 거쳐야 함 (**VLAN 간 라우팅**)

| 효과 | 내용 |
|---|---|
| 브로드캐스트 범위 축소 | 불필요한 트래픽 감소 |
| 보안 | 부서·용도별로 네트워크 분리 |
| 유연성 | 자리를 옮겨도 배선 변경 없이 설정만으로 소속 변경 |
| 비용 | 네트워크마다 스위치를 따로 둘 필요 없음 |

**포트 VLAN**

- 스위치 **포트마다** VLAN 번호를 지정 — 그 포트에 연결된 기기는 해당 VLAN 소속
- 단순하지만 스위치 여러 대에 걸치면 VLAN 수만큼 스위치 간 케이블이 필요

**태그 VLAN (IEEE 802.1Q)**

- 이더넷 프레임에 **VLAN ID가 담긴 태그(4바이트)**를 붙여 전송
- 한 가닥의 케이블(**트렁크 링크**)로 여러 VLAN의 프레임을 함께 전달
- 받는 쪽 스위치는 태그를 보고 어느 VLAN의 프레임인지 구분

| 구분 | 포트 VLAN | 태그 VLAN |
|---|---|---|
| 식별 방법 | 포트 번호 | 프레임 안의 VLAN ID |
| 포트 종류 | 액세스 포트 (VLAN 1개) | 트렁크 포트 (VLAN 여러 개) |
| 주 용도 | 단말 연결 | 스위치 ↔ 스위치, 스위치 ↔ 가상화 서버 |

**VLAN의 한계**

- VLAN ID는 **12비트** → 최대 4,094개 — 대규모 데이터 센터·클라우드의 이용자 수를 감당 못 함
- L2 기술이라 라우터를 넘어 확장하기 어려움
- 경로상의 모든 스위치에 VLAN 설정 필요 → 가상 서버가 이동할 때마다 변경

<details><summary>가상화 서버에 연결된 스위치 포트를 트렁크로 설정하는 이유는?</summary>

물리 서버 한 대 안에 서로 다른 VLAN에 속한 가상 서버가 여러 대 있기 때문이다. <br>
물리 NIC 하나로 여러 VLAN의 프레임을 주고받아야 하므로 태그 VLAN으로 연결하고, <br>
하이퍼바이저의 가상 스위치가 태그를 보고 해당 가상 서버로 프레임을 전달한다.
</details>

## 🔑 최종 정리

> 한 줄 요약: VLAN은 스위치에서 LAN을 논리적으로 분할해 물리 배선과 무관하게 브로드캐스트 도메인을 나누는 기술로, 포트 단위로 지정하는 포트 VLAN과 프레임에 VLAN ID 태그를 붙여 한 링크로 여러 VLAN을 전달하는 태그 VLAN(802.1Q)이 있으며, ID가 4,094개로 제한되고 L2 범위를 넘기 어렵다는 한계가 있다
