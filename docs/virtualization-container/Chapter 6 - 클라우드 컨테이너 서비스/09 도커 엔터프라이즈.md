# 도커 엔터프라이즈

> 여러 클라우드와 온프레미스의 컨테이너 환경을 **중앙에서 집중 관리**해 멀티 클라우드를 실현하는 기업용 컨테이너 플랫폼

## 도커 엔터프라이즈란

> Docker Enterprise : 도커 엔진에 클러스터 관리·보안·이미지 관리 기능과 기술 지원을 더한 **기업용 유료 제품**

- 특정 클라우드의 서비스가 아니라 **소프트웨어 제품** → AWS·애저·GCP·온프레미스 어디에나 설치
- 어느 환경에서든 **같은 플랫폼·같은 조작**으로 컨테이너 운영 → 멀티 클라우드·하이브리드 클라우드 구성
- 오케스트레이션 도구로 **스웜과 쿠버네티스를 모두** 지원 — 한 클러스터에서 함께 사용 가능

```
          중앙 관리 화면 (웹 UI · API · 접근 제어)
        ┌──────────┬──────────┬──────────┐
        ▼          ▼          ▼          ▼
     온프레미스     AWS        애저        GCP
     (도커 엔진 + 스웜 / 쿠버네티스 클러스터)
```

**변천**

| 시기 | 내용 |
|---|---|
| 2017년 | 도커사가 기업용 제품을 Docker Enterprise Edition(EE)으로 정리, 무료판은 Community Edition(CE) |
| 2019년 | **미란티스(Mirantis)** 가 도커사의 엔터프라이즈 사업을 인수 |
| 이후 | 제품명이 Mirantis Kubernetes Engine 등으로 변경되어 미란티스가 개발·지원 |

- 도커사는 인수 이후 Docker Desktop·Docker Hub 등 **개발자용 도구**에 집중

## 도커 엔터프라이즈에서 사용 가능한 도구

| 도구 (당시 명칭) | 현재 명칭 | 역할 |
|---|---|---|
| Docker Engine - Enterprise | Mirantis Container Runtime (MCR) | 기업용 컨테이너 런타임 — 보안 강화·인증·장기 지원 |
| UCP (Universal Control Plane) | Mirantis Kubernetes Engine (MKE) | **클러스터 중앙 관리** — 웹 UI, 스웜·쿠버네티스 통합 운영, 접근 제어 |
| DTR (Docker Trusted Registry) | Mirantis Secure Registry (MSR) | **사내 전용 레지스트리** — 이미지 저장, 취약점 검사, 서명 |

**UCP (MKE) 의 주요 기능**

| 기능 | 내용 |
|---|---|
| 통합 관리 화면 | 노드·컨테이너·서비스·볼륨·네트워크를 한 화면에서 조작 |
| 역할 기반 접근 제어 (RBAC) | 사용자·팀별로 조작 가능한 리소스와 권한을 제한 |
| 사내 인증 연계 | LDAP·Active Directory 등과 연동 |
| 오케스트레이터 선택 | 같은 클러스터에서 스웜 서비스와 쿠버네티스 워크로드를 함께 실행 |

**DTR (MSR) 의 주요 기능**

| 기능 | 내용 |
|---|---|
| 프라이빗 레지스트리 | 이미지를 외부에 공개하지 않고 사내에 보관 |
| 취약점 검사 | 이미지에 포함된 패키지의 알려진 취약점을 검사 |
| 이미지 서명 | 신뢰할 수 있는 이미지만 배포되도록 서명·검증 |
| 이미지 승격·복제 | 검증을 통과한 이미지를 운영용 저장소나 다른 레지스트리로 자동 전달 |

**클라우드의 관리형 서비스와 비교**

| 구분 | 도커 엔터프라이즈 | 관리형 서비스 (EKS·GKE·AKS) |
|---|---|---|
| 형태 | 직접 설치하는 소프트웨어 | 클라우드가 운영하는 서비스 |
| 실행 장소 | 온프레미스·모든 클라우드 | 해당 클라우드 |
| 플랫폼 운영 | 이용자 (벤더 기술 지원) | 사업자 |
| 강점 | 환경에 상관없이 동일한 운영·보안 정책 | 구축이 쉽고 클라우드 서비스와 연계 |

<details><summary>무료로 쓰는 도커와 도커 엔터프라이즈는 무엇이 다를까?</summary>

컨테이너를 만들고 실행하는 핵심 기능은 같다. 무료판(도커 엔진, 당시 CE)만으로도 개발과 소규모 운영에는 충분하다. <br>
엔터프라이즈는 여기에 여러 클러스터의 중앙 관리, 사용자별 권한 제어, 사내 레지스트리와 취약점 검사, 벤더의 기술 지원과 장기 보안 패치를 더한 것이다. <br>
즉 기술 자체보다 기업이 요구하는 통제·보안·지원 체계를 사는 제품이다.
</details>

## 🔑 최종 정리

> 한 줄 요약: 도커 엔터프라이즈는 어느 클라우드나 온프레미스에든 설치해 같은 방식으로 운영하는 기업용 컨테이너 플랫폼으로, 스웜과 쿠버네티스를 함께 중앙 관리하는 UCP와 사내 보안 레지스트리인 DTR로 구성되며, 2019년 미란티스에 인수되어 현재는 Mirantis Kubernetes Engine(MKE)·Mirantis Secure Registry(MSR)로 제공된다
