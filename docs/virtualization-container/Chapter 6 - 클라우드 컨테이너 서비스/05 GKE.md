# GKE

> GCP의 **관리형 쿠버네티스 서비스** — 쿠버네티스를 만든 구글이 직접 제공

## GKE란

> GKE (Google Kubernetes Engine) : 구글 클라우드에서 쿠버네티스 클러스터를 실행·관리해 주는 서비스

- 쿠버네티스는 구글의 사내 컨테이너 관리 시스템(Borg)의 경험을 바탕으로 개발되어 2014년 공개
- GKE는 주요 클라우드 중 **가장 먼저** 나온 관리형 쿠버네티스 서비스 (2015년 정식 출시)
- 컨트롤 플레인의 구축·이중화·업그레이드를 구글이 담당

---

## GKE의 작동 방식

```
kubectl / 콘솔 ──▶ 컨트롤 플레인 (구글 관리)
                        │
                 ┌──────┴──────┐
                 ▼             ▼
             노드 풀 A       노드 풀 B        ← 같은 사양의 노드 묶음
           [VM][VM][VM]     [VM][VM]         ← Compute Engine 가상 머신
             파드 …          파드 …
```

- 노드 : Compute Engine의 가상 머신
- **노드 풀** : 같은 설정(머신 유형 등)을 가진 노드의 그룹 — 용도별로 나누어 구성

**운영 모드**

| 구분 | Standard | Autopilot |
|---|---|---|
| 노드 관리 | 이용자가 노드 풀 구성·관리 | **구글이 노드까지 관리** |
| 과금 | 노드(VM) 단위 | 파드가 요청한 자원 단위 |
| 자유도 | 높음 | 제한적 (보안·운영 권장 설정이 강제) |
| 어울리는 경우 | 세밀한 제어가 필요 | 운용 부담을 줄이고 싶음 |

**자동화 기능**

| 기능 | 내용 |
|---|---|
| 자동 업그레이드 | 컨트롤 플레인·노드의 쿠버네티스 버전을 자동으로 올림 |
| 자동 복구 | 상태가 나쁜 노드를 감지해 다시 만듦 |
| 클러스터 오토스케일러 | 파드를 놓을 자리가 부족하면 노드를 늘리고, 남으면 줄임 |

## 리전과 영역

| 용어 | 내용 |
|---|---|
| 리전 | 데이터 센터가 모여 있는 지리적 지역 |
| 영역 (존) | 리전 안의 독립된 구역 — AWS의 가용 영역에 해당 |

| 클러스터 유형 | 컨트롤 플레인 | 특징 |
|---|---|---|
| 영역 클러스터 | 한 영역에 1개 | 저렴하지만 그 영역에 장애가 나면 클러스터 조작 불가 |
| 리전 클러스터 | 리전 내 **여러 영역에 복제** | 영역 장애·업그레이드 중에도 컨트롤 플레인 유지 → 운영 환경 권장 |

- 리전 클러스터는 노드도 여러 영역에 분산 → 가용성은 높지만 노드 수(비용) 증가

## 쿠버네티스는 GKE가 가장 좋을까?

- GKE의 강점 : 쿠버네티스 원조답게 새 기능 반영이 빠르고, 자동화 기능과 Autopilot 등 완성도가 높음
- 그러나 **무조건 GKE가 정답은 아님**

| 판단 기준 | 내용 |
|---|---|
| 기존 환경 | 이미 AWS·애저에 데이터베이스·네트워크가 있다면 그쪽 서비스(EKS·AKS)가 연계에 유리 |
| 팀의 경험 | 익숙한 클라우드의 권한·감시 체계를 그대로 활용 |
| 주변 서비스 | 함께 쓸 데이터 분석·AI·데이터베이스 서비스 |
| 비용·계약 | 요금 체계, 기존 계약·할인 |

- 쿠버네티스 API는 어디서나 같으므로 **쿠버네티스 밖의 조건**이 선택을 좌우

<details><summary>Autopilot과 Cloud Run은 둘 다 노드 관리가 없는데 무엇이 다를까?</summary>

Autopilot은 노드만 구글이 관리할 뿐 여전히 쿠버네티스 클러스터다. 디플로이먼트, 서비스 같은 쿠버네티스 객체를 직접 다루고 쿠버네티스 생태계 도구를 쓸 수 있다. <br>
Cloud Run은 쿠버네티스를 드러내지 않고 컨테이너 이미지 하나를 올리면 URL까지 만들어 주는 더 단순한 서비스다. <br>
여러 구성 요소를 세밀하게 제어해야 하면 Autopilot, 단순한 웹 서비스를 빨리 올리려면 Cloud Run이 어울린다.
</details>

## 🔑 최종 정리

> 한 줄 요약: GKE는 쿠버네티스를 만든 구글이 제공하는 관리형 쿠버네티스 서비스로, 노드 풀 단위로 노드를 구성하고 Standard와 노드까지 맡기는 Autopilot 모드가 있으며, 컨트롤 플레인을 여러 영역에 복제하는 리전 클러스터로 가용성을 높일 수 있지만, 어느 클라우드의 쿠버네티스를 쓸지는 기존 환경과 주변 서비스에 따라 결정한다
