# AKS

> 애저의 **관리형 쿠버네티스 서비스** — 컨트롤 플레인은 애저가 운영하고 이용자는 노드와 애플리케이션만 관리

## AKS란

> AKS (Azure Kubernetes Service) : 애저에서 쿠버네티스 클러스터를 손쉽게 배포·운영하게 해 주는 서비스

- 컨트롤 플레인의 구축·감시·유지 보수를 애저가 담당
- Microsoft Entra ID(구 Azure AD) 인증, Azure Monitor, Azure DevOps·GitHub Actions 등 **마이크로소프트 제품군과 연계**
- 리눅스 컨테이너뿐 아니라 **윈도우 컨테이너** 노드도 지원

---

## AKS의 작동 방식

```
kubectl / 포털 ──▶ 컨트롤 플레인 (애저 관리)
                        │
              ┌─────────┴─────────┐
              ▼                   ▼
        시스템 노드 풀        사용자 노드 풀
        [VM][VM]             [VM][VM][VM]     ← 애저 가상 머신 (확장 집합)
      클러스터 필수 파드       애플리케이션 파드
```

| 구성 요소 | 내용 |
|---|---|
| 컨트롤 플레인 | API 서버·etcd·스케줄러 등 — 애저가 관리 |
| 노드 | 애저 가상 머신 — 이용자의 구독에 생성, 요금 발생 |
| 노드 풀 | 같은 구성의 노드 그룹 |
| 시스템 노드 풀 | CoreDNS 등 클러스터 운영에 필요한 파드를 실행 |
| 사용자 노드 풀 | 이용자의 애플리케이션 파드를 실행 |

- 클러스터 오토스케일러로 노드 수 자동 조절, 노드 자동 복구·업그레이드 지원

---

## 리전과 가용 영역

| 용어 | 내용 |
|---|---|
| 리전 | 데이터 센터가 모여 있는 지리적 지역 |
| 가용 영역 | 리전 안에서 전원·냉각·네트워크가 독립된 데이터 센터 구역 |

- 클러스터를 만들 때 가용 영역을 지정하면 **노드가 여러 영역에 분산** 배치
- 한 영역에 장애가 발생해도 다른 영역의 노드에서 파드가 계속 실행 → 가용성 향상
- 주의 : 가용 영역을 지원하는 리전에서만 가능, 디스크는 영역에 묶이므로 파드 재배치 시 고려 필요

## 가상 쿠블릿이란

> Virtual Kubelet : 쿠블릿인 척하며 쿠버네티스에 **가상의 노드**로 등록되어, 파드를 실제 노드가 아닌 외부 서비스에서 실행시키는 오픈 소스

- 쿠블릿 : 각 노드에서 파드를 실행·관리하는 에이전트
- AKS에서는 가상 쿠블릿을 이용한 **가상 노드** 기능으로 파드를 **ACI**에서 실행

```
        AKS 클러스터
┌──────────────────────────────┐
│ 일반 노드(VM)   일반 노드(VM)   │ ← 평소 부하 처리
│   파드 파드       파드 파드     │
│                              │
│ 가상 노드 (가상 쿠블릿)         │ ← 부하 급증 시 넘치는 파드 배치
└───────────┬──────────────────┘
            ▼
     ACI에서 컨테이너 실행 (서버리스, 초 단위 기동)
```

| 구분 | 노드(VM) 추가 | 가상 노드 (ACI) |
|---|---|---|
| 확장 속도 | VM 기동에 수 분 | 수 초~수십 초 |
| 과금 | VM 기동 시간 | 파드 실행 시간 (초 단위) |
| 용도 | 지속적인 부하 | 일시적인 급증 (**버스팅**) |

<details><summary>가상 노드만으로 모든 파드를 실행하면 안 될까?</summary>

가상 노드에서 실행되는 파드는 실제로는 ACI의 컨테이너라서 데몬셋, 일부 볼륨·네트워크 기능 등 쿠버네티스 기능에 제약이 있다. <br>
또 ACI는 초 단위 과금이라 짧게 쓰면 저렴하지만 계속 켜 두면 VM보다 비싸질 수 있다. <br>
그래서 평소 부하는 일반 노드로 처리하고, 갑자기 늘어난 부하만 가상 노드로 넘기는 구성이 일반적이다.
</details>

## 🔑 최종 정리

> 한 줄 요약: AKS는 애저가 컨트롤 플레인을 운영하는 관리형 쿠버네티스 서비스로, 노드는 시스템·사용자 노드 풀로 구성해 여러 가용 영역에 분산할 수 있고, 가상 쿠블릿을 이용한 가상 노드로 급증한 파드를 서버리스인 ACI에서 빠르게 실행(버스팅)할 수 있다
