# 코딩 가이드라인

> 코드 가이드라인을 통해 재사용 가능한 코드를 만들어내 유용성과 적용성을 높임

## MISRA-C 코딩 표준

> 유럽 자동차 연합에서 자동차 탑재 소프트웨어 신뢰성 및 호환성을 높이게다는 의도로 개발한 C 코딩 표준

### MISRA-C: 2012

- 143개 규칙과 16개 디렉티브로 구성 
  - 디렉티브는 정적 분석 도구로 자동 검증이 어려운 개발 프로세스 차언의 가이드라인
  - 143개 규칙은 22개 영역으로 구분 
- 규칙 분류가 Mandatory, Required, Advisory 3단계로 세분화 

![](misra-c.png){ width=600, height=800 }

> 150개 정도의 규칙을 모두 준수하면서 프로그래밍 하기 어려워 자동 검사 도구 사용 - Lint

## 시큐어 코딩

> 구현 단계에서 해킹 공격 유발 가능성이 있는 보안 취약점을 제거하는 프로그래밍 기법

### CERT C 코딩 표준 

> 규칙과 권고로 구성

> 각 규칙에 심각성, 발생 가능성, 교정 비용 수준을 나타내는 숫자 할당 

![](cert.png){ width=600, height=800 }


> MISRA-C는 제한적인 임베디드 시스템의 안전성에 초점 <br> CERT C는 일반적인 애플리케이션 환경을 포함한 전반적인 보안성과 취약점 방지에 더 방점
