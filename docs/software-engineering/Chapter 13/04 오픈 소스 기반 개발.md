## 오픈 소스 활용 환경

### 오픈 소스 검색 및 분석 도구

- Solr, ElasticSearch, Lucene 등 존재
- 크롤링, 인덱싱, 순위 기반 결과, 메트릭, 코드 취약성 분석 등의 기능 제공

### 오픈 소스 개발 지원 도구

> 코드 통합, 문서화 등 다양한 업무에 사용

- Git : 분산 버전 제어 시스템
- Eclipse IDE : Java 중심 통합 개발 환경
- BootStrap : 프론트엔드 구성 요소 제공 라이브러리
