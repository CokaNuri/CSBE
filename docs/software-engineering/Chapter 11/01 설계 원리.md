# 모듈화 설계 개요

> 모듈화 : 소프트웨어 공학 원리 중 가장 근간이 되는 개념

**모듈화의 장점**

- 이해하기 쉽다
- 유지보수하기 쉽다
- 팀 단위 개발에 용이하다

**설계**: 요구사항 분석 결과를 소프트웨어 형상으로 변경하는 단계이며, 모듈 개념이 실질적으로 적용되는 단계

- 계층적인 구조 : 시스템 → 서브시스템 → 하위 기능 영역 → 모듈로 구성
- 설계 결과가 모듈로 구성된다

> **좋은 모듈화 구조** : 상호 연관성 있는 것들끼리 묶고(응집력 ↑), 모듈 간 상호작용이 간단한 형태(결합력 ↓)
