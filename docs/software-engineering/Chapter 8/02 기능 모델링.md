# 기능 모델링

## 기능 모델링 개요

> 요구사항을 입력받아 소프트웨어가 해야 할 기능이 무엇인지를 식별하는 과정

> 유스 케이스 다이어그램을 이용해 분석 결과 표현

## 유스 케이스 다이어그램

> 시스템의 최상위 수준에 해당하는 기능을 사용자 관점으로 나타낸 것 

> 사용자가 시스템을 통해 제공받는 주요 기능을 나타냄

(1) 요구사항 정의 내용 검토
(2) 시스템 경계 설정
(3) 시스템 명칭 정의
(4) 시스템 외부 액터 식별 및 역할 정의
(5) 액터가 시스템에서 사용하는 기능 식별
(6) 액터와 기능간 관계 정의
(7) 기능에 대한 설명서 작성

- 동사형으로 표현
- 독립적으로 존재하지 않고 다른 유스 케이스와 관계를 맺고 있음
- 포함 관계 : 반드시 호출되어 실행되어야 하는 동작
- 확장 관계 : 선택적으로 호출되는 관계 


## 유스 케이스 설명서

> 각 유스 케이스에 대한 설명서를 작성해야 함

> 식별 정보와 기능의 상세 흐름 정의 

- 유스 케이스 이름
- 고유 식별자
- 액터
- 우선순위
- 설명
- 관계
- 트리거 

- 정상 시나리오 정의부
  - 유스 케이스 내부 기능을 단계별로 작성
  - 액터와 시스템 간의 상호작용에 초점
- 예외 처리 정의부
  - 정상 시나리오 각 단계에서 발생 가능한 예외 처리 작성
